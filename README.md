# Deathstare_Hero
3D Web Rythum Game (html, javascript) 
Also contains Easy python script for mp3 to song chart generator.

Just something fun I did for my nonsence Youtube channel.
https://www.youtube.com/@Sparkandstorymedia

Game uses JSON files to hold level data and 3D Models can be GLB or FBX

Two Python Scripts;

"Auto" - Creates song note JSON chart to copy into your level JSON
         Threshold can can changed for more or less notes. (Easier --> Harder)
"Manual" - Song plays and YOU type in the notes and it records input. 
          Creates JSON to copy into your game folder.
